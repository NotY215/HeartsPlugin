# Support

Paper 1.21+ Minecraft plugin providing smooth heart displays, optional Vault economy display, Geyser/Floodgate Bedrock actionbar support, ArmorStand heart rendering, death messages, and automatic updates.

## Getting help

For usage questions and reproducible problems:

1. Read the README and project documentation.
2. Check existing GitHub issues.
3. Open a new issue when the problem is not already documented.

Issues: https://github.com/NotY215/HeartsPlugin/issues

## What to include

Include the project version or commit, operating system, relevant dependency versions, exact error messages and a minimal reproduction when possible.

Do not post passwords, API keys, OAuth secrets, private files or other sensitive information.

## Feature requests

Explain the use case and how the proposed feature fits the existing project architecture. Feature requests that require a major redesign may be discussed separately from bug reports.
