# Contributing to HeartsPlugin

Thanks for contributing to HeartsPlugin.

## Before contributing

Read the README and project documentation first. Keep changes focused on the existing architecture and avoid unrelated rewrites.

## Development

- Project: Paper 1.21+ Minecraft plugin providing smooth heart displays, optional Vault economy display, Geyser/Floodgate Bedrock actionbar support, ArmorStand heart rendering, death messages, and automatic updates.
- Stack: Java 21, Gradle, Paper API, optional Vault, Geyser/Floodgate.
- Build or validation: `./gradlew build`

## Pull requests

1. Create a focused branch from the default branch.
2. Make the smallest change that solves the issue.
3. Test the affected functionality before opening the pull request.
4. Update documentation when behavior, commands, formats or public interfaces change.
5. Explain what changed and how it was tested.
6. Do not include credentials, private tokens, generated secrets or unrelated binary files.

## Code style

Follow the formatting and structure already used by the repository. Preserve existing naming and platform conventions.

## Issues

Use the repository issue tracker for reproducible bugs and feature discussions: https://github.com/NotY215/HeartsPlugin/issues
