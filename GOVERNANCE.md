# Governance

## Maintainer

HeartsPlugin is maintained by **NotY215 (Shreyas Mishra)**.

The maintainer is responsible for repository direction, releases, licensing decisions, security handling and final decisions on changes.

## Contributions

Contributors are welcome to submit issues and pull requests. Contributions should follow CONTRIBUTING.md and the Code of Conduct.

Technical decisions should be discussed openly in issues or pull requests when practical. The maintainer may reject changes that conflict with the project's scope, architecture, security requirements or license.

## Changes to governance

The maintainer may update this policy as the project grows. Significant changes will be documented in repository history.
